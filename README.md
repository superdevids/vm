# vm

A virtual machine for make.fun's tiny stack ISA (tiny-stack-vm-01).

    node main.ts

Reads `$MAKEFUN_INPUT_DIR/<id>/{program.bin,input.bin}`, writes
`$MAKEFUN_OUTPUT_DIR/<id>/{stdout.bin,exit.txt}`. Node 22, standard library only.
